# homebrew-type-stats

Homebrew tap for [TypeStats](https://github.com/dctmfoo/type-stats), a macOS menu bar app that
counts key presses and clicks per app.

## Install

```sh
brew install --cask dctmfoo/type-stats/type-stats
```

or

```sh
brew tap dctmfoo/type-stats
brew install --cask type-stats
```

`Casks/type-stats.rb` is updated by the release workflow in `dctmfoo/type-stats` from its signed
and notarized GitHub releases.
